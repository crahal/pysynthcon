# Replication and validation

The four notebooks in `empirical_examples/` use only settings from major
methodological papers. Each downloads immutable public bytes with requests,
verifies SHA256, checks a reference specification, and runs all eleven
interfaces on a shared outcome panel. Executed outputs are committed.

## What each check establishes

| Example | Reference specification | Numeric target | Predeclared tolerance |
|---|---|---|---|
| California | R synthdid no-covariate example, 1989 onset | ATT −15.603827872733849 | absolute $10^{-6}$ |
| Basque | pysyncon/Synth predictor specification | 1975–1997 ATT −0.6995647842110987; Catalonia/Madrid weights 0.850816306/0.149183694 | 2.5% relative ATT; 0.025 absolute weights |
| Germany | pysyncon ADH two-stage V specification | 1990–2003 ATT −1555.1346777620479 | 2.5% relative |
| Kansas | authors' R augsynth no-covariate vignette | Ridge ASCM ATT −0.0401 | absolute 0.001 |

California's target was independently generated by running the pinned R
synthdid source and also matches the paper's rounded −15.6 result. The Basque
and Germany high-precision numbers are **upstream implementation references**,
not numbers printed to that precision in the papers. Their tolerance is the
upstream parity suite's stated tolerance. Kansas uses the authors' vignette's
printed value. Differences in third-decimal donor weights can arise from
nested optimization and numerical environments; tolerances are not widened
after seeing a run.

The Basque fitting period is 1960–1969; the common-comparison ATT begins 1970,
while the upstream reference ATT uses 1975–1997. Its upstream donor pool also
includes Spain's aggregate, with zero fitted weight. Germany's historical
training and predictor convention includes 1990, even though the comparison
Panel defines 1990 as post-treatment. This is isolated in `replicate`, explained
in the notebook, and never used by the generic native estimators. Kansas uses
2012.25 as in the authors' example; the outcome is a natural logarithm.

The California dataset contains outcomes only. The notebook reproduces the
SDID specification, **not** ADH (2010)'s original covariate-based SCM predictor
specification. Native outcome SCM on that dataset is a separate comparison.

## Independent numerical checks

Offline fixtures in `tests/fixtures` contain small artificial numeric panels
and outputs generated by R, not by the Python estimators. SDID is checked
against R's donor weights, time weights and ATT. SCUL lambda.min is checked
against the R procedure, using glmnet's solver. Lasso prediction tolerances
allow its stopping error; its alpha grid and optimal penalty are checked
separately. The analytic orthogonal-design lasso test also verifies penalty
normalization and reconstruction on original units.

Other tests cover known effects, multi-treated additive models, label/order
alignment, no treated-post leakage, invariance, nearest-donor selection,
case aggregation, placebo exclusion/rank rules, HTTP errors, hashes and
corrupt caches. Adapter tests compare returned predictions to the actual
upstream fitted object's predictions.

## Re-run

```bash
python -m pip install -r requirements-replication.txt
python -m pip install -e '.[docs,dev]'
python -m pytest
python -m pytest -m network
python scripts/execute_notebooks.py --output-dir /tmp/pysynth-notebooks
```

The tested numeric environment uses Python 3.12, NumPy 2.0.2, SciPy 1.13.1,
pandas 2.3.3 and scikit-learn 1.7.2; all principal replication requirements
are pinned. BLAS and platform differences can still matter. Run with
`OPENBLAS_NUM_THREADS=1` for stable, economical small-panel computation.

R is required only to regenerate the independent R fixtures. The standard
Python test suite does not require R or network access.

To independently re-run the references without rewriting fixtures, install
the R packages `glmnet` and `jsonlite`, then run:

```bash
python scripts/validate_r.py
# For a custom R library location:
python scripts/validate_r.py --r-library /path/to/R-library
```

The checked-in SCUL fixture used R 4.6.2 and glmnet 5.2. Its selected penalty
matches to $10^{-9}$. Default glmnet coefficient stopping leaves a maximum
path difference of about 0.007 outcome units on this smooth test panel;
the test permits 0.01 and also checks a high-precision glmnet refit at
$10^{-5}$ absolute path tolerance. These are solver parity checks, not a
precision claim about a causal effect in the original SCUL study.

## Boundaries of the empirical claims

Applying SCUL or individual SC to a classic aggregate dataset is a new
application. It does not reproduce the original SCUL scanner-data study,
the Vagni–Breen motherhood study, or costofcare's survey analysis. The original
data access and case construction are not supplied by this repository.
IndividualSC implements a documented costofcare-style estimator; MSCMT
predictor-weight optimization is not reproduced. Those original empirical
estimates therefore remain unverified here, rather than being assigned
invented replication targets.
